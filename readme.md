Animated Tic-Tac-Toe

A modern and responsive Tic-Tac-Toe game built with HTML, CSS, and JavaScript, featuring animations, sound effects, confetti, and dark/light mode.

🎮 Features
✕ vs ◯ two-player gameplay

- Win and draw detection
- Score tracking
- Light/Dark mode
- Animated moves
- Confetti and particle effects on winning
- Sound effects
- Responsive design
- New game/reset functionality
- Technologies
  HTML5 – Page structure
  CSS3 – Styling and animations
  JavaScript – Game logic and interactions
  Tailwind CSS – Utility classes
  Canvas API – Confetti effects
  Web Audio API – Sound effects
  📁 Project Structure
  tic-tac-toe/
  ├── index.html
  ├── style.css
  ├── app.js
  └── README.md
  🚀 How to Run
  Download or clone the project.
  Keep index.html, style.css, and app.js in the same folder.
  Open index.html in your browser.

That's it! 🎮

🧠 How It Works

The game stores the 9 board positions in a JavaScript array. Each click places the current player's symbol, then the game checks the possible winning combinations. When someone wins, the score is updated and animations, sound, confetti, and particles are triggered.

The game also supports switching between light and dark themes using CSS classes.
